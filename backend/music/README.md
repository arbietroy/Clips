# Background music library

Put royalty-free tracks here. ClipForge picks a track whose **folder or file name** matches the mood
it detected for each video or clip:

```
music/
  upbeat/        happy, pop, positive
  inspirational/ motivational, uplifting, cinematic
  chill/         lofi, calm, ambient
  dramatic/      epic, intense
  emotional/     sad, piano
  energetic/     edm, rock, workout
  corporate/     business, tech
  funny/         quirky, playful
  suspense/      tension, mystery
  hiphop/        trap, beat
```

Free sources: YouTube Audio Library, Pixabay Music, Uppbeat, Free Music Archive (check each licence).
Music is automatically looped, faded in and out, and ducked under the voice.
