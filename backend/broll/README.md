# B-roll library

Drop your own clips here and name them with keywords, e.g. `city-skyline-night.mp4`,
`typing-laptop.mp4`, `money-cash.mp4`. ClipForge matches file names against what is being said.

When nothing matches, it downloads matching stock footage automatically if you set a free key:
`PIXABAY_API_KEY` (https://pixabay.com/api/docs/) or `PEXELS_API_KEY` (https://www.pexels.com/api/).
Downloads are cached so each clip is only fetched once.
