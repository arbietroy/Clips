# B-roll library

Drop your own clips here and name them with keywords, e.g. `city-skyline-night.mp4`,
`typing-laptop.mp4`, `money-cash.mp4`. ClipForge matches file names against what is being said.

When nothing matches and `PEXELS_API_KEY` is set (free at https://www.pexels.com/api/), it downloads
matching stock footage automatically and caches it in `output/_broll_cache/`.
